Gauß-Werkstatt

Drei Gleichungen, drei Unbekannte – und jetzt?

Mit zwei Gleichungen kommst du per Einsetzen oder Gleichsetzen noch gut zurecht. Bei drei Gleichungen mit drei Variablen wird Probieren schnell mühsam. Versuch es selbst, bevor du das Verfahren kennenlernst.

Fazit

Probieren ist Glückssache. Wir brauchen ein Verfahren, das immer funktioniert, egal wie krumm die Zahlen sind: das Gauß-Verfahren. Es formt das LGS so lange um, bis man die Lösung von unten nach oben ablesen kann.

1. Zwei Schreibweisen – ein System

Ein lineares Gleichungssystem (LGS) kann man ausführlich mit Variablen schreiben oder kompakt als erweiterte Koeffizientenmatrix. In der Matrix stehen nur die Zahlen vor den Variablen (die Koeffizienten). Der senkrechte Strich ersetzt das Gleichheitszeichen.

LGS
Matrix
Übersetzungsregeln: ① Variablen immer in derselben Reihenfolge (x, y, z) sortieren. ② Fehlt eine Variable, steht in der Matrix eine 0. ③ Steht nur x da, ist der Koeffizient 1, bei −x ist er −1. ④ Zahlen ohne Variable kommen nach rechts hinter den Strich.

Tipp: Oben rechts kannst du jederzeit zwischen LGS und Matrix umschalten. Alle Aufgaben werden dann in der gewählten Darstellung angezeigt.

2. Drei erlaubte Umformungen

Diese Umformungen verändern die Lösungsmenge nicht (Äquivalenzumformungen). Sie gelten immer für die ganze Gleichung, also auch für die rechte Seite!

↕
Gleichungen vertauschen. Die Reihenfolge der Gleichungen ist egal. Schreibweise: I ↔ II. Nützlich, wenn oben links eine 0 steht.
·k
Eine Gleichung mit einer Zahl k ≠ 0 multiplizieren. Schreibweise: 2·II. Mit 0 multiplizieren ist verboten, denn dann ginge die Information der Gleichung verloren.
+
Ein Vielfaches einer Gleichung zu einer anderen addieren. Schreibweise: II − 2·I (zu Gleichung II wird das (−2)-Fache von Gleichung I addiert). Oft werden ② und ③ kombiniert, z. B. 3·II − 2·I. So vermeidet man Brüche.

3. Ziel: die Nullertreppe (Stufenform)

Man formt so lange um, bis unterhalb der „Treppe“ nur noch Nullen stehen. Gearbeitet wird Spalte für Spalte von links nach rechts:

  1. Mit Zeile I erzeugt man Nullen in der x-Spalte von II und III.
  2. Danach erzeugt man mit Zeile II (nicht mehr mit I!) eine Null in der y-Spalte von III.

Dann steht unten eine Gleichung mit nur noch einer Variablen. Man rechnet rückwärts: zuerst z aus III, dann y aus II, dann x aus I.

4. Drei mögliche Fälle

✅ Genau eine Lösung

Die Treppe ist vollständig. Unten steht z. B. 10z = 30. Ergebnis: L = {(1 | 2 | 3)}.

⛔ Keine Lösung

Eine Zeile wird zu 0 = 5 (links nur Nullen, rechts nicht). Das ist ein Widerspruch. Ergebnis: L = { }.

♾️ Unendlich viele Lösungen

Eine Zeile wird zu 0 = 0. Sie ist immer wahr, liefert aber keine Information. Eine Variable ist frei wählbar.
